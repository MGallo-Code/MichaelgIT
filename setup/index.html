Remote Setup

This will let me connect to your computer remotely so I can help you. It only takes a minute.

1 Open a terminal as Administrator

Right-click the Start button and select PowerShell (Admin) or Terminal (Admin). Click "Yes" if asked to allow changes.
Open Terminal (search for "Terminal" in Spotlight).

2 Paste this command and press Enter

irm michaelgit.com/setup/setup-remote.ps1 | iex
curl -sL michaelgit.com/setup/setup-remote.sh | sudo bash
This may take a minute or two. You'll see green checkmarks as each step completes.

3 Read me the info on screen

The script will show your IP address, username, and computer name. Just text or read those to me and I'll take it from there!
