Remote Setup

This will let me connect to your computer remotely so I can help you. It only takes a minute.

1 Download the setup file for your computer

Click the button that matches your computer type:

Windows Mac

2 Run the file

Windows: Right-click the downloaded file and select "Run with PowerShell." If asked, click "Run as Administrator" and allow changes.
Mac: Open Terminal (search for "Terminal" in Spotlight). Type: sudo bash ~/Downloads/setup-remote.sh and press Enter. Enter your password when asked.

3 Read me the info on screen

The script will show your IP address, username, and computer name. Just text or read those to me and I'll take it from there!
